### Price policy

The listing also showed a **£9.74 "pay now"** figure on an ~18-hour countdown. That is
deliberately **not** on screen: the video outlives the countdown, and an ad still quoting an
expired promotional price is a false advertised price. On-screen copy uses the standing
£12.98 / was £27.96 / −54%, which stays true after the timer runs out.

No performance, durability, or comparative claims appear anywhere — only the price, the piece
count, and the shipping term, all read directly off the listing.

## Beat structure (10s, designed to loop)

| Time | Action | On-screen text |
|---|---|---|
| 0–2.5s | Case descends in the light column, bits drifting in orbit | `24 IN 1` / `RATCHET SCREWDRIVER SET` |
| 2.5–5s | Bits streak inward and snap magnetically into the tray | `24 MAGNETIC BITS` / `SNAP INTO PLACE` |
| 5–7.5s | Ratchet lifts, spins, settles; dust shockwave rings out | — |
| 7.5–10s | Camera pulls back and orbits to the exact opening framing | `WAS £27.96` / `NOW £12.98` / `SAVE 54%` → `FREE SHIPPING` / `TAP THE YELLOW CART` |

The last frame is composed to match the first, so the clip loops without a visible cut.

## How the text is done

Text is **never** generated by the video model — image models render lettering as gibberish,
and a garbled price is unusable. The footage is rendered clean, then type is burned in post
with ffmpeg `drawtext` using real font files (Metropolis ExtraBold, Montserrat ExtraBold),
sliding in with alpha ramps and drop shadows.

This means the price is editable without re-rendering the video, and without spending credits.
Change the strings in the item list and re-run the burn against the clean plate.
